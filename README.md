# Yangjian Wu's Personal Website

Personal academic website hosted at [jett-wu.github.io](https://jett-wu.github.io/), built with the [al-folio](https://github.com/alshedivat/al-folio) template.

## Editing

- **About / homepage:** `_pages/about.md`
- **Publications:** `_bibliography/papers.bib`
- **Projects:** `_projects/`
- **Blog posts:** `_posts/`
- **Social links & email:** `_data/socials.yml`
- **Site-wide settings:** `_config.yml`

Push to `main` to auto-deploy via GitHub Actions (Deploy site workflow).
